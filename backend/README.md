# Krishi Sarathi - FastAPI Backend

Enterprise-grade backend serving crop recommendations and explainability maps.

## Quick Start
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch dev server:
   ```bash
   uvicorn app.main:app --reload
   ```
3. Navigate to Swagger UI: http://127.0.0.1:8000/docs
