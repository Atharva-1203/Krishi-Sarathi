# Crop Recommendation V3 Dataset

This folder contains the selected and audited dataset for training the Krishi Sarathi V3 crop prediction engine.

## Directory Contents
*   `dataset.csv`: The clean, 2,200-row crop recommendation dataset.
*   `dataset_card.md`: Technical documentation of dataset features, provenance, statistics, and distributions.

For detail forensics and statistical metrics, refer to `docs/v3_rebuild/data_forensics.md`.
