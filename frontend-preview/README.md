# Krishi Sarathi - Static Project Preview

This folder contains a completely static HTML/CSS/JS preview version of the project. It can be opened directly from Windows Explorer (no package servers or compilers required).

## Features Included
1. **Bilingual Navigation**: Complete translation between English and Marathi.
2. **Theme Toggles**: Light and Dark theme synchronizations cached in local storage.
3. **Interactive Maps**: Vector SVG selector mapping Pune and Solapur profiles.
4. **Mock Inference**: Submitting the form redirects directly to styled recommendation results.
5. **No Dependencies**: Pure vanilla HTML5, CSS3, and JavaScript.

## How to Run
Double-click `preview.bat` at the repository root to automatically open the home page in your default web browser.
