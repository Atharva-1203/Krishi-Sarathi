# Land Degradation Metadata

- **Original Database**: ICAR-NBSS&LUP Harmonized Land Degradation Database for India (Maharashtra subset).
- **Thematic Layers on Portal**:
  - Soil Erosion (derived from soil loss equations) - `SoilErosionLayer` / `Soil_Loss_of_India`
  - Harmonised Degradation Data (salinity, sodicity, acidity, erosion combinations) - `ld_Harmonised` / `Harmonised_Data`
- **Spatial Resolution**: 1:250,000 scale.
- **Reporting Units**: Hectares.
- **Methodology**: Integrates remote sensing soil reflectance anomaly data with field verification and soil chemical database overlays (pH, ESP, EC).
