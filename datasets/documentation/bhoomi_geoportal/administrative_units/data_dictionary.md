# Administrative Units Data Dictionary

| Column Name | Description | Data Type | Key Type | Example / Allowed Values |
|-------------|-------------|-----------|----------|--------------------------|
| district_name | Standard English name of the district in Maharashtra | String | - | AHMEDNAGAR, BEED, NASHIK |
| lgd_code | Local Government Directory standard district code | Integer | Primary | 472, 473, 493 |
| division | Administrative division of the district | String | - | Nashik, Amravati, Nagpur, Pune, Aurangabad, Konkan |
| geoportal_spelling | The exact spelling key used in the Bhoomi Geoportal's spatial database and CQL filters | String | Alternate | AHMADNAGAR, BID, AMARAVATI, NASIK, RAIGARH |
