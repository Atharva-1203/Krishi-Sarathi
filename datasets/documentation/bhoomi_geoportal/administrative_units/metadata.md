# Administrative Units Metadata

- **Original Source**: ICAR-National Bureau of Soil Survey and Land Use Planning (NBSS&LUP), Nagpur.
- **Portal Link**: https://bhoomigeoportal-nbsslup.in/BHOOMI_StateWise/Maharashtra.php
- **Spatial Resolution**: Administrative Boundary Vector Layer (District and Block boundaries at 1:250,000 scale).
- **Administrative Resolution**: District and Block (Taluka/Tehsil) levels.
- **Update Frequency**: Static, based on Census 2011 boundaries.
- **Coordinate Reference System**: EPSG:3857 (WGS 84 / Pseudo-Mercator) for display, EPSG:4326 for spatial queries.
- **Known Anomalies**: The portal maps 35 districts. The district of **Palghar** (created in 2014 from Thane) is not separately cataloged, indicating boundaries are pre-2014 (Census 2011 standard).
