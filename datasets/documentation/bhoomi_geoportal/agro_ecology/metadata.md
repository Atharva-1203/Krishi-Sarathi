# Agro-Ecology Metadata

- **Data Sources**: NBSS&LUP Climate Database, IMD Grid Weather Data.
- **Classifications Represented**:
  - AER (Agro-Ecological Regions) 1992 (based on 20-region model)
  - AER 2015 (revised agro-ecological zoning)
  - AESR (Agro-Ecological Subregions) 1999 (60-subregion model for India)
- **Spatial Resolution**: Polygon boundaries digitized at 1:1,000,000 and 1:250,000 scale.
- **Variables included**: Rainfall class, Aridity Index, Moisture Index, Evapotranspiration (PET, AET), Water deficit/surplus, LGP (Length of Growing Period).
