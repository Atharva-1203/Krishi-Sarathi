# Watershed Planning Metadata

- **Original Data Source**: Hydrological Unit Map of India (Central Ground Water Board - CGWB, and National Remote Sensing Centre - NRSC), customized by ICAR-NBSS&LUP.
- **Thematic Layers on Portal**:
  - Drainage network (stream order overlays) - `drainage`
  - Water Bodies (dams, lakes, major rivers digitized) - `waterShedLayer` / `Waterbodies`
  - Major River Basins - `basinLayer` / `Major_River_Basins`
- **Mapping Scale**: 1:250,000 scale.
- **Spatial Resolution**: Vector line and polygon datasets.
- **Hydrological Classification**: Watersheds delineated hierarchically (Basin -> Catchment -> Sub-catchment -> Watershed).
