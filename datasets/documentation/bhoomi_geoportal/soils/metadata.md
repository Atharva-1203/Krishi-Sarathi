# Soils Spatial Metadata

- **Source Agency**: ICAR-National Bureau of Soil Survey and Land Use Planning (NBSS&LUP), Nagpur.
- **Mapping Scales**:
  - 1:1,000,000 (State level Soils dataset - `1m_soils_state` / `1_1M_Soil`)
  - 1:250,000 (District-wise Soil Resource Mapping - `250k_soils_state` / `250k_Soils`)
  - 1:50,000 (Detailed Soil Survey - only available for Bhandara, Chandrapur, Gondia, and Yavatmal districts)
- **Soil Survey Methodology**: Grid-based profile studies, laboratory physical/chemical analysis, and remote sensing imagery interpretation.
- **Attribute Formats**: WMS GetFeatureInfo JSON and MySQL table schemas.
