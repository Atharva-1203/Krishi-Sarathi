# Outlier and Dataset Analysis

Master dataset: 4,513 rows, 16 crop classes, no nulls, no exact duplicate rows,
no duplicate feature rows, and no exact train/validation/test feature overlap.

Sugarcane has 1,010 rows (22.38%); Masoor has 12. The max/min class imbalance
is 84.17x. Feature support is unusually discrete: seven pH values, 15 rainfall
values, and seven temperature values. Dataset provenance, label correctness,
and near-duplicate conclusions under a scientific distance threshold are NOT
VERIFIED.

Observed production request distribution is NOT VERIFIED because no request
telemetry or persisted API-request corpus exists in the repository.
