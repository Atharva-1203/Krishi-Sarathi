This report documents the performance evaluation of candidate models on the V3 balanced training dataset.

## 2. Why ExtraTrees Won
Extremely Randomized Trees outperformed other candidates for the following reasons:
1.  **Maximum Variance Reduction**: ExtraTrees chooses split thresholds completely at random, rather than searching for the absolute best threshold like Random Forests. This extra randomization acts as an effective regularizer, reducing variance and avoiding overfitting on continuous agronomic bounds.
2.  **Smooth Class Probabilities**: ExtraTrees generates highly calibrated probability distributions when combined with Sigmoid Platt Scaling. It achieved a multi-class Brier score of `0.0162` (lower is better), outperforming Random Forest (`0.0175`).
3.  **Clean Separation of Borders**: Tabular agricultural parameter distributions have clear, logical thresholds. The decision boundaries generated by ExtraTrees align cleanly with physiological tolerances.
4.  **Low Latency**: Inference takes under 8 ms, meeting live REST API demands.
