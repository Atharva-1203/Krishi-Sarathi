# Temporal Information Strategy

This document evaluates the temporal features available to capture annual weather and crop sowing dynamics.

## 1. Recommended Temporal Features
- **Sowing Year**: Captures long-term climate shift trends.
- **Season (Kharif/Rabi/Summer)**: Crucial, as rainfall and humidity distributions differ completely between seasons.
- **Standardized Precipitation Index (SPI)**: Can be calculated from Phase 2 rainfall databases to classify drought/monsoon cycles.
- **Rainfall Trend**: Moving average of rainfall over the previous 3 years to capture ground-water recharge rates.
