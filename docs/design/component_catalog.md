# Krishi Sarathi - Component Catalog

This catalog documents the reusable React/Next.js components.

## 1. Core Layout Components
- **`Header.tsx`**: Navigation header incorporating a live timezone clock, API status checks (port 8000), and language switches.
- **`Sidebar.tsx`**: Left navigation menu containing state mottos and icons.
- **`BackgroundEffects.tsx`**: Ambient particle engine floating soft agricultural green elements on radial gradient backdrops.

## 2. Page Components
- **`LandingPage.tsx`**: Hero banner showing government Soil Card datasets (779K) and ML metrics.
- **`PredictionDashboard.tsx`**: Crop prediction input form with Pydantic validation boundaries.
- **`ResultsDisplay.tsx`**: Suitability results showing Top-3 recommendations, water requirement/growing duration chips, and SHAP progress charts.
- **`InsightsPage.tsx`**: Interactive SVG selector of Pune, Satara, Kolhapur, Sangli, and Solapur districts.
- **`AnalyticsPage.tsx`**: Technical details mapping model F1 accuracy (99.59%) and parameters.
