# Krishi Sarathi - Design System Tokens

Centralized styling rules blending NASA Earth Data, Windy, and Apple motion guidelines.

## 1. Core Color System
- **Primary**: Deep Forest Green (`#080f08` Dark / `#e8f0e8` Light).
- **Secondary**: Agricultural Emerald (`#10b981`).
- **Accent**: Golden Harvest (`#f59e0b` / `#d97706`).
- **Supporting**: Earth Brown (`#78350f`), Soil Black (`#0e1a0e`), Rain Blue (`#3b82f6`).

## 2. Elevations & Blurs
- **Glassmorphism**: `backdrop-blur-md bg-[var(--bg-glass)] border border-[var(--border-color)]`.
- **Shadow Glows**: `shadow-lg shadow-emerald-500/5` (emerald ambient glow).
