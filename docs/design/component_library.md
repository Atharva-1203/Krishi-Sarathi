# Krishi Sarathi - Re-architected Component Library

Reusable Next.js TSX components catalog.

## 1. Visual Layouts
- **`Header.tsx`**: Displays clock tickers, language dropdown toggles, and health checks.
- **`Sidebar.tsx`**: Left navigation link sidebar showing Sanskrit tags.
- **`BackgroundEffects.tsx`**: Renders ambient floating seeds and soft green blurs.

## 2. User Interfaces
- **`LandingPage.tsx`**: Cinematic hero sections showcasing 779K Soil Health Cards statistics.
- **`PredictionDashboard.tsx`**: Multi-step wizard separating District selection, climate parameters, and nutrients.
- **`ResultsDisplay.tsx`**: Suitability rings, SHAP contribution bars, and printable report modal templates.
- **`MaharashtraMap.tsx`**: Dynamic WGS84 SVG map projected directly from Survey of India coordinate layers.
