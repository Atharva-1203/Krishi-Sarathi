# Krishi Sarathi - Project Architecture

This document maps out the system directories and explains the modular design.

## Folder Layout Description

- `datasets/`: Contains raw government data caches, processed data structures, final registers, and data catalogs.
- `ml/`: Standard production ML directory layout (configs, preprocessing, model registers).
- `backend/`: Future API backend server code.
- `frontend/`: Future React/Next.js dashboard interface.
- `docs/`: Centralized research and metadata documentation.
- `reports/`: Diagnostic, data quality, and model evaluations.
- `presentation/`: Pitch decks and slides.
- `assets/`: Image assets and static diagrams.
- `.github/`: GitHub action workflows and issue templates.
